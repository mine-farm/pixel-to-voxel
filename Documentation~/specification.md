# 기능 명세 · v0.1

## 목적과 범위

Unity 에디터에서 PNG 도트 이미지에 일정한 두께를 주어 일반 메시와 프리팹을 생성한다.
3D 형태 추정이나 복셀 개별 편집은 수행하지 않는다. 외부 런타임 라이브러리를 요구하지 않는다.
새 저장소의 독립 UPM 패키지로 구현하며 게임 프로젝트 자체는 수정하지 않는다.

## 사용자 작업

1. 변환 그룹 생성/불러오기.
2. 프로젝트 PNG, Sprite, 폴더를 여러 개 입력.
3. 공통 변환 설정 또는 프리셋 적용.
4. 사전 검사에서 정상/경고/오류, 예상 메시 규모 확인.
5. 모델별 포함 여부 선택 및 3D 미리보기.
6. 경고 파일 포함/제외를 결정하고 변환 시작.
7. 진행률, 취소, 파일별 결과 및 이력 확인.
8. 원본 수정 후 같은 그룹에서 다시 검사·생성.

## 입력

- PNG 원본, PNG를 참조하는 프로젝트 Sprite, 프로젝트 폴더.
- 폴더는 재귀 검색. Sprite 시트는 개별 Sprite로 확장. 동일 소스는 GUID + local file ID로 중복 제거.
- 확대된 도트는 Pixel Step으로 블록 크기 지정. 블록 중앙의 색을 사용하며 평균 보간하지 않음.
- 입력이 비어 있거나, PNG가 잘못됐거나, 샘플링 크기가 맞지 않거나, 모든 픽셀이 투명하면 오류.
- Packed Sprite 또는 축소 임포트된 Sprite는 수정 방법과 함께 오류 처리.
- 원본 임포터 설정을 변경하지 않음.

## 메시

- 불투명 픽셀의 XY 위치 및 RGB 색상 유지. 알파 기준 이상은 불투명으로 처리.
- Z축 양방향으로 절반씩 두께 생성. 실제 깊이 = Pixel Size × Depth.
- 기둥 내부와 인접한 기둥 사이의 보이지 않는 면 제거. 구멍 안쪽의 노출 면은 유지.
- 깊이 방향은 동일 색상 기둥으로 합침. 앞뒤 면의 색이 다른 경우는 지원하지 않음.
- 정점 법선은 평평하게 유지. 큰 메시에는 32비트 인덱스 적용.
- 투명 외곽 여백 제거 또는 캔버스 유지, 중심/하단 원점, XY 반전, 방향 회전 지원.

## 팔레트와 머티리얼

- 개별 모드: 모델별 팔레트/머티리얼.
- 공유 모드: 그룹 전체가 한 팔레트/머티리얼 공유.
- 이미지 직사각형 패킹 대신 고유 RGB 색상 타일을 저장하고 메시 UV를 타일 중심에 배치.
- 타일 4×4, Point, Clamp, mipmap 없음. 색상 슬롯은 저장된 순서를 유지하며 신규 색상만 뒤에 추가.
- 고정 아틀라스 크기로 모델 일부를 재생성하거나 취소해도 기존 UV가 변하지 않음.
- 팔레트 용량 초과는 출력 전 안내. 더 큰 아틀라스의 새 그룹 또는 색상 수 축소 필요.
- URP / Built-in Unlit 지원. HDRP, 사용자 지정 셰이더 선택, 조명 머티리얼은 후속 범위.

## 저장과 재생성

- 기본 출력 루트와 그룹 에셋 이름으로 결과 그룹 폴더 생성.
- 프리팹별 폴더에 메시와 프리팹 배치. 공용 리소스는 그룹 Shared 폴더에 보관.
- 파일명 충돌은 안정적인 소스 ID 접미사로 구분. 다른 소유자의 에셋은 덮어쓰지 않음.
- 같은 그룹이 생성한 결과는 갱신하거나 건너뛰기 가능.
- 기존 에셋 자체를 갱신하여 참조 유지. Prefab은 기존 내용을 불러와 생성기 소유 요소만 갱신.
- 그룹과 프리셋은 ScriptableObject. 이력은 입력, 출력, 적용 설정, 마지막 성공 시각, 통계를 보관.
- 생성 후 출력 루트·팔레트 모드·크기는 잠금. 생성된 그룹의 복제본은 원본 소유 출력 수정 차단.
- 실패한 파일은 사유를 남기고 나머지 작업을 계속함. 소유권/공용 팔레트 등의 배치 전체 오류는 쓰기 전에 차단.
- 취소 시 기존 완료 결과 유지. 배치 전체의 트랜잭션/롤백은 지원하지 않음.

## 추가 편의 기능

- 크기/두께/원점/알파 등의 설정 프리셋 저장/적용.
- 콜라이더 없음 / Box / 비볼록 Mesh 중 선택.
- 미리보기에서 회전/확대축소, 정점·삼각형·생성 크기 표시.
- 대량 검사 목록은 30개씩 페이지 표시.
- 입력이나 설정 변경 시 검사 캐시 무효화. 생성 전 소스 변경 여부 재확인.

## 검수 기준

- 단색 1픽셀은 6면, 인접한 2픽셀은 10면 생성.
- 깊이가 늘어나도 기둥 메시의 정점 수는 증가하지 않음.
- 알파 경계와 투명 검정색을 정확히 구분.
- 기존 팔레트에 정렬상 앞서는 색을 추가하고 다시 불러와도 이전 UV 유지.
- 같은 프리팹을 재생성해도 기존 Mesh/Material/Texture/Prefab ID 및 씬 참조 유지.
- 공용 팔레트에 색상을 추가해도 건너뛴 모델의 색상이 변하지 않음.
- 경고 파일을 제외하면 해당 출력은 생성하지 않음.
- 원본 PNG의 임포터 설정은 생성 전후 동일.
- 큰 메시, 잘못된 입력, 취소, 이름 충돌, 다른 그룹의 소유권을 처리.

## 이후 범위

`.vox`/FBX 내보내기, 복셀 직접 편집, 비균일 두께, 애니메이션 변환,
자동 재생성 감시, 팔레트 재압축/크기 변경, GPU 인스턴싱 자동 구성은 포함하지 않는다.
